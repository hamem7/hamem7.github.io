# استخراج متشابهات «السورة مع نفسها» (الصفحات 1–233 → السور 2–45)

المصدر: `docs/متشابهات السورة مع نفسها.pdf` (فيه طبقة نص، لكنها مقلوبة الحروف وأرقام الآيات مشوّهة بخط الملف).
لا يُخزَّن نص الآيات: الناتج أرقام فقط، ويُجلب النص وقت العرض من `database/quran-uthmani.json`.

## الخطوات
```
cd tools/mutashabihat-extract && mkdir -p work
pdftotext -f 2 -l 279 ../../docs/*.pdf work/layout.txt
pdftotext -raw -f 2 -l 279 ../../docs/*.pdf work/raw.txt
python3 -I 1_assign_sections.py          # يربط كل قسم (صفحات العناوين) بسورته بالمطابقة مع المصحف
python3 -I 2_extract_groups.py 45        # يخرج work/groups.json للسور حتى 45
```
- حدود الوحدات: نهاية كل موضع «رقم + ))/})»؛ بداية المجموعة: `*`.
- المطابقة: 3-grams على النص بلا تشكيل ولا ألف (يتجاوز تبديل أحرف لام-ألف في الملف)، بالاتجاهين لأن الأسطر مقلوبة،
  ومحصورة في آيات السورة التي تحوي كلمة العنوان.
- العنوان (anchorPhrase): يُفكّ من سطر العنوان ويُطابق نافذة كلمات في الآية (Dice على الحروف)، وإلا أطول مقطع مشترك.
- التحقق: نفس الخط على السور 46–77 يعيد 190 من 262 مجموعة مطابقة تمامًا للـ seed المدقَّق (متوسط Jaccard 0.83)،
  و95٪ من المجموعات «المكتملة» (بلا موضع غير محسوم) مطابقة تمامًا.
- `candidates-surahs-2-45.json`: المرشحات (`complete=false` تعني أن موضعًا أو أكثر لم يُحسم وسقط من المجموعة).
