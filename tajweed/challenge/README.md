# تحدي التجويد — ركن التجويد في المنصة

نموذج تعليمي تفاعلي (HTML + JavaScript بلا مكتبات ولا خدمات خارجية) لإعادة تصوّر ركن التجويد في منصة «حمٓ».
**لا يعدّل أي ملف من المنصة ولا يعتمد على أي مسار منها وقت التشغيل.** كل ما يحتاجه منسوخ داخل هذا المجلد وموثَّق المصدر.

> **الحالة: مُدمَج في المنصة.** هذا المجلد يحلّ محلّ شاشات «أبطال التجويد» القديمة: زر التجويد في المنصة يستدعي `openTajweedSection` (core/app.js) فيحمّل `tajweed/tajweed-map.html` و`tajweed/tajweed-map.js`، وهذا الأخير يركّب الوحدة هنا داخل Shadow DOM تحت ترويسة المنصة الوحيدة وبخلفيتها. اللغة من `AppState.currentLang` والمظهر من `<html data-theme>` (فلا ترويسة ولا أزرار لغة/مظهر خاصة بالركن). الشاشات القديمة (`tajweed/tajweed-activity|entry|summary|…` و`engine/tajweed*`) بقيت دون استدعاء من أي زر.

## التشغيل

```bash
python3 -m http.server 8130      # من جذر المنصة، ثم افتح http://localhost:8130/ واضغط «التجويد»
```

## الاختبار

```bash
node tajweed/challenge/tools/verify.mjs            # مراجعة المحتوى (نص قرآني، أمثلة، لغتان، حروف، خط، صور)
node tajweed/challenge/tests/games.test.mjs        # منطق الألعاب
node tajweed/challenge/tests/mushaf.test.mjs       # منطق قسم المصحف
node tajweed/challenge/tests/e2e.mjs               # متصفح حقيقي على المنصة نفسها (Playwright/Chromium) بعد تشغيل الخادم أعلاه
```

إعادة بناء بنك الآيات (يقرأ من المنصة قراءةً فقط): `node tajweed/challenge/tools/build-data.mjs`.

## خريطة الملفات

| المسار | الدور |
|---|---|
| `index.html` | الصفحة الوحيدة (شريط علوي للنموذج + `#app`) |
| `js/app.js` | الموجّه والشاشات: الرئيسية، صفحة الحكم، الدرس، النتيجة، المصادر |
| `js/play.js` | تشغيل الأسئلة والتغذية الراجعة (5 أنواع ألعاب) |
| `js/engine.js` | **محرك الأسئلة** (منطق خالص، بلا DOM): يبني المستويات ويفحص الإجابات |
| `js/quran.js` | عرض النص القرآني: النص كلمة سليمة + طبقة تلوين/لمس فوقه (لا تقطيع للحروف) |
| `js/arabic.js` | تقسيم الكلمات إلى مقاطع حرفية (مشترك مع أدوات البناء) |
| `js/viz.js` | رسوم SVG أصلية لكل حكم |
| `js/i18n.js` · `js/store.js` · `js/audio.js` | نصوص الواجهة (ع/En) · حفظ التقدّم محليًا · تلاوة اختيارية |
| `data/rules.js` | **محتوى الأحكام** (تعريف، شرح، خطوات، أمثلة، أبيات، مراجع) ثنائي اللغة |
| `data/pool.js` | بنك الآيات (مولَّد آليًا، لا يُعدَّل يدويًا) |
| `css/` · `assets/` | التنسيق · خطوط وشعار (نسخ مستقلة موثَّقة) |
| `tools/` | بناء البنك، الكاشف المستقل، المراجعة الآلية، الخادم |
| `tests/` | اختبار الألعاب واختبار المتصفح الشامل |
| `docs/` | `DESIGN.md` · `CONTENT_SOURCES.md` · `REVIEW_CHECKLIST.md` · `TEST_REPORT.md` · `screenshots/` |

## كيف تضيف حكمًا أو لعبة

- **حكم جديد:** أضف كائنه في `data/rules.js` (`RULES` + اسمه في مرحلة من `STAGES` + `CONFUSABLES`) ورسمًا في `js/viz.js`؛ وإن احتاج كاشفًا أضف قاعدته في `tools/lib/detect.mjs` ثم `node tools/build-data.mjs`. `tools/verify.mjs` سيفحص الباقي.
- **لعبة جديدة:** مولّد `genXxx` + `checkXxx` في `js/engine.js` وعارض في `js/play.js`، ثم أضفها لـ`buildLevel`. اختبار الألعاب يفحصها تلقائيًا إن أضفت فرعًا لها في `tests/games.test.mjs`.

## الدمج لاحقًا (بعد اعتمادك فقط)

لم يُنفَّذ أي دمج. عند الاعتماد: تُنقل الشاشات لتُحقن داخل `#app-root` تحت `#main-header` الوحيد (يُحذف الشريط العلوي هنا)،
ويُستبدل `store.js` بـ`database/tajweedDB.js`، وتُضاف ألوان الشاشات لقوائم المظهر الداكن حسب `CLAUDE.md`.
