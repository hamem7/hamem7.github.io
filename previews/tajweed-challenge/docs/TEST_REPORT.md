# تقرير الاختبارات

| الفحص | الأمر | النتيجة |
|---|---|---|
| مراجعة المحتوى | `node tools/verify.mjs` | ✓ نص ٥٧١ آية (٢٣٣٧ كلمة) مطابق للمصحف حرفًا حرفًا؛ ٤٩ مثال درس موثَّق بمصدرين؛ لغتان كاملتان؛ حروف الأحكام مطابقة للكاشف؛ الخط القرآني والملفات مطابقة للمنصة |
| منطق الألعاب | `node tests/games.test.mjs` | ✓ ~٦٢٠٠ سؤال مولَّد (كل حكم × ٣ مستويات × ٢٥ بذرة + تحديات المحطات + الكبير): إجابة صحيحة واحدة، وتفسير لكل خيار |
| متصفح حقيقي | `node tests/e2e.mjs` | ✓ ٧٤١ فحصًا: ٥ أنواع ألعاب، كل حكم (الدرس ٥ خطوات + ٣ مستويات بإجابات صحيحة ← ٣ نجوم)، إجابات خاطئة ← تفسير ولا نجوم، تحديات المحطات والكبير، المصادر، المسح، ع/En، RTL/LTR، داكن، ٣ أحجام بلا تمرير أفقي، بلا أخطاء console |
| ترويسة المنصة | `node tools/check-header.mjs` | ✓ (لم تتأثر؛ المجلد داخل previews المستثنى) |
| المظهر الداكن للمنصة | `node tools/gen-dark-theme.mjs --check` | ✓ |
| سلامة المنصة | `git status` | لا تعديل على أي ملف خارج `previews/tajweed-challenge/` |

## ما كشفته الاختبارات وأُصلح
1. تلوين الحروف بعناصر مفصولة كسر وصل الحروف وموضع الشدّة ← طبقة تلوين فوق نص سليم.
2. أسئلة «اضغط الكلمة» كانت تُولَّد أحيانًا بلا كلمة خاطئة ← شرط كلمتين خاطئتين على الأقل.
3. كاشف المد الطبيعي عدّ مد البدل («ءَامَنُوا») ← استُبعد.
4. اقتباسان من المتن كتبتهما من الذاكرة خالفا النسخة ← صُحّحا بالمطابقة البصرية مع الـPDF.

## مشكلات معروفة / حدود
- **الصوت لم يُختبر** (الشبكة محجوبة): الزر يعمل ويفشل بلطف مع رسالة.
- **الاختبار على Chromium فقط**؛ لم يُجرَّب Safari/iOS وFirefox. قياسات الخط قد تختلف قليلًا في طبقة التلوين.
- **لقطات الشاشة** في `docs/screenshots/` (هاتف/تابلت/حاسوب، ع/En، داكن) لمراجعتك البصرية؛ لم يفحص أحد بصريًا كل شاشة على كل حجم.
- ٥ أسئلة لكل مستوى والخيارات الخاطئة من المتشابهات؛ لم يُجرَّب مع أطفال.
- البنك يغطي الفاتحة وسور جزء عمّ فقط.
- الرسائل الإنجليزية للأحكام تحتاج مراجعة لغوية.

## حالة الإنجاز
| مكتمل | يحتاج مراجعة/استكمال |
|---|---|

| ثنائي اللغة، داكن، متجاوب، تقدّم محفوظ | تجربة مع أطفال ومتصفحات أخرى |
